# Releases — CI Workflow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rewrite `.github/workflows/build.yml` so CI is green, the `continuous` rolling release actually publishes, and versioned `vX.Y.Z` tags publish stable GitHub Releases with git-cliff notes.

**Architecture:** Four jobs — `test` (Linux, gates everything) → `build` (matrix: ubuntu/macos/windows) → then one of two publishers depending on trigger: `continuous` (recreates the rolling prerelease on push to `main`) or `release` (stable release on a `v*` tag). This replaces the broken `build-rust → build-tauri → create-release` chain.

**Tech Stack:** GitHub Actions, `tauri-apps/tauri-action@v0`, `orhun/git-cliff-action@v4`, `softprops/action-gh-release@v2`.

## Context (read first)

- **Root cause being fixed:** the old `build-rust` job ran `cargo build --release` on `ubuntu-latest` **without installing the Linux system deps** (`glib-2.0`/`gobject-2.0` not found via pkg-config). Because `build-tauri` and `create-release` had `needs: build-rust`, they were skipped on **every** run since Feb 2026 — so nothing was ever built or released. Evidence: latest run `27818931031`, job "Build Rust", error `The system library glib-2.0 required by crate glib-sys was not found`.
- **Already done (do NOT redo):** `scripts/bump-version.sh`, `cliff.toml`, and the "Cutting a release" section in `CLAUDE.md` are committed (`c0088d2`, `8d31b7d`). `CHANGELOG.md` does **not** exist yet — it is generated on the first real `bump-version.sh` run.
- **Design spec:** `docs/superpowers/specs/2026-06-23-releases-design.md` (the source of truth for the "why").
- **Verification method:** CI changes are verified **empirically via Actions runs**, not unit tests. Each task's "test" = push to a branch / trigger a run / read the logs.

## Global Constraints

- Linux system deps to install (exact): `libwebkit2gtk-4.1-dev libsoup-3.0-dev libjavascriptcoregtk-4.1-dev libgtk-3-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev`.
- Commit style: Conventional Commits (`ci:`, `fix(ci):`, …).
- Use action versions: `actions/checkout@v4`, `actions/setup-node@v4`, `actions/upload-artifact@v4`, `actions/download-artifact@v4`, `dtolnay/rust-toolchain@stable`, `Swatinem/rust-cache@v2`, `tauri-apps/tauri-action@v0`, `softprops/action-gh-release@v2`, `orhun/git-cliff-action@v4`, `dev-drprasad/delete-tag-and-release@v1.1`.
- There is **no** `npm run lint` script; the frontend check command is `npm run check` (svelte-check).

## Known unknowns (set expectations)

- The **macOS** (`--target universal-apple-darwin`) and **Windows** builds have **never run** (always skipped behind the failing `build-rust`). Task 3 is dedicated to getting them green; expect to diagnose real failures there using the systematic-debugging skill.

### Task 1: Rewrite the workflow file

**Files:**
- Modify (full rewrite): `.github/workflows/build.yml`

**Produces:** a single workflow with `test`, `build` (3-platform matrix), `continuous`, and `release` jobs. After this task the file is syntactically valid; later tasks verify each path actually works.

- [ ] **Step 1: Replace the entire contents of `.github/workflows/build.yml` with:**

```yaml
name: Build and Release

on:
  push:
    branches: [main]
    tags: ['v*']
  pull_request:
    branches: [main]

env:
  CARGO_TERM_COLOR: always

jobs:
  test:
    name: Test
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - uses: Swatinem/rust-cache@v2
        with:
          workspaces: src-tauri
      - name: Install Linux dependencies
        run: |
          sudo apt-get update
          sudo apt-get install -y libwebkit2gtk-4.1-dev libsoup-3.0-dev libjavascriptcoregtk-4.1-dev libgtk-3-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: npm
      - run: npm ci
      - name: Rust tests
        run: cargo test --release
        working-directory: src-tauri
      - name: Frontend typecheck
        run: npm run check

  build:
    name: Build (${{ matrix.platform }})
    needs: test
    strategy:
      fail-fast: false
      matrix:
        include:
          - platform: ubuntu-latest
            args: ""
          - platform: macos-latest
            args: "--target universal-apple-darwin"
          - platform: windows-latest
            args: ""
    runs-on: ${{ matrix.platform }}
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: npm
      - uses: dtolnay/rust-toolchain@stable
        with:
          targets: ${{ matrix.platform == 'macos-latest' && 'aarch64-apple-darwin,x86_64-apple-darwin' || '' }}
      - name: Install Linux dependencies
        if: matrix.platform == 'ubuntu-latest'
        run: |
          sudo apt-get update
          sudo apt-get install -y libwebkit2gtk-4.1-dev libsoup-3.0-dev libjavascriptcoregtk-4.1-dev libgtk-3-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev
      - uses: Swatinem/rust-cache@v2
        with:
          workspaces: src-tauri
      - run: npm ci
      - uses: tauri-apps/tauri-action@v0
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          NO_STRIP: ${{ matrix.platform == 'ubuntu-latest' && '1' || '' }}
        with:
          args: ${{ matrix.args }}
      - name: Upload artifacts (Linux)
        if: matrix.platform == 'ubuntu-latest'
        uses: actions/upload-artifact@v4
        with:
          name: linux-artifacts
          path: |
            src-tauri/target/release/bundle/**/*.deb
            src-tauri/target/release/bundle/**/*.AppImage
      - name: Upload artifacts (macOS)
        if: matrix.platform == 'macos-latest'
        uses: actions/upload-artifact@v4
        with:
          name: macos-artifacts
          path: src-tauri/target/release/bundle/**/*.dmg
      - name: Upload artifacts (Windows)
        if: matrix.platform == 'windows-latest'
        uses: actions/upload-artifact@v4
        with:
          name: windows-artifacts
          path: |
            src-tauri/target/release/bundle/**/*.msi
            src-tauri/target/release/bundle/**/*.exe

  continuous:
    name: Continuous Release
    needs: [test, build]
    runs-on: ubuntu-latest
    if: github.event_name == 'push' && github.ref == 'refs/heads/main'
    permissions:
      contents: write
    steps:
      - uses: actions/checkout@v4
      - name: Get version
        id: get_version
        run: echo "version=$(grep '^version' src-tauri/Cargo.toml | head -1 | sed 's/.*\"\(.*\)".*/\1/')" >> "$GITHUB_OUTPUT"
      - uses: actions/download-artifact@v4
        with:
          path: artifacts
          pattern: "*-artifacts"
          merge-multiple: true
      - name: Delete previous continuous release
        uses: dev-drprasad/delete-tag-and-release@v1.1
        with:
          tag_name: continuous
          delete_release: true
          github_token: ${{ secrets.GITHUB_TOKEN }}
        continue-on-error: true
      - name: Publish continuous release
        uses: softprops/action-gh-release@v2
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        with:
          tag_name: continuous
          name: "Continuous Build"
          body: |
            Rolling build from `main` (bleeding-edge). For stable releases see [Releases](https://github.com/${{ github.repository }}/releases).

            **Version:** ${{ steps.get_version.outputs.version }}
            **Commit:** ${{ github.sha }}
          files: |
            artifacts/**/*
          prerelease: true
          generate_release_notes: true

  release:
    name: Stable Release
    needs: [test, build]
    runs-on: ubuntu-latest
    if: startsWith(github.ref, 'refs/tags/v')
    permissions:
      contents: write
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
      - name: Generate release notes
        id: cliff
        uses: orhun/git-cliff-action@v4
        with:
          config: cliff.toml
          args: --latest --strip header
        env:
          GITHUB_REPO: ${{ github.repository }}
      - uses: actions/download-artifact@v4
        with:
          path: artifacts
          pattern: "*-artifacts"
          merge-multiple: true
      - name: Publish stable release
        uses: softprops/action-gh-release@v2
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        with:
          body: ${{ steps.cliff.outputs.content }}
          files: |
            artifacts/**/*
          prerelease: false
```

### Task 3: Get macOS + Windows builds green

**Goal:** the `build` matrix passes on all three platforms. These jobs have never run before, so treat each failure with the systematic-debugging skill (root-cause before fixing).

**Consume:** the `build` matrix from Task 1.

- [ ] **Step 1: Read the failing platform logs**

Run, for each failing platform:
```bash
gh run view --log-failed $(gh run list --branch main --limit 1 --json databaseId --jq '.[0].databaseId') | grep -E 'Build \(macos|Build \(windows'
```
Identify the exact error per platform (common ones: missing Rust target for macOS universal, `tauri-action` arg issues, Windows code-signing expectations, `tauri.conf.json` bundle config).

- [ ] **Step 2: Diagnose root cause per platform (systematic-debugging)**

For each failure: read the full error, form one hypothesis, make the smallest change, push to a fresh `ci/platform-fix` branch, open a PR, watch only the relevant job. Do **not** bundle multiple platform fixes in one push — isolate them.

- [ ] **Step 3: Apply the minimal fix and verify**

Likely fixes (only apply the one matching the actual error):
- macOS universal: ensure both targets are installed (already in the matrix: `targets: aarch64-apple-darwin,x86_64-apple-darwin`); if the universal build itself errors, check `tauri.conf.json` has no macOS-only misconfig.
- Windows: if it expects signing, `tauri-action` builds an unsigned `.msi`/`-setup.exe` by default — confirm `bundle.windows` in `tauri.conf.json` isn't requiring a signature.
- Both: confirm `tauri-apps/tauri-action@v0` is compatible; if a newer tag is needed, bump and note it.

After the fix: `gh pr merge --squash`, then `gh run watch` the main run until `Build (macos-latest)` and `Build (windows-latest)` are both green.

- [ ] **Step 4: Verify all-platform artifacts upload**

Run: for the latest main run, confirm `linux-artifacts`, `macos-artifacts`, `windows-artifacts` all exist (PR checks or the run's artifacts page). Then re-check the `continuous` release now carries `.deb`/`.AppImage`, `.dmg`, `.msi`/`.exe`.

- [ ] **Step 5: Commit** the per-platform fixes (`fix(ci): ...` or `fix(build): ...`).

## Out of scope (do not do in this plan)

- In-app update notifications (Tauri updater) — separate effort.
- Code signing / notarization (macOS notary, Windows Authenticode) — publish unsigned for now.
- Deduplicating the double build on `git push --follow-tags` (one run for main→continuous, one for tag→release) — acceptable cost; YAGNI.

## Final verification

After Task 4, all four are true:
1. A push to `main` → `test` + 3×`build` green → `continuous` prerelease updated with all-platform artifacts.
2. A `v*` tag push → `test` + 3×`build` green → stable GitHub Release with git-cliff notes + all-platform artifacts.
3. A PR → `test` + `build` run, no release published.
4. `./scripts/bump-version.sh 0.1.0` then `git push --follow-tags origin main` produces the first real stable release and bootstraps `CHANGELOG.md`.
